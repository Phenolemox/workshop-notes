# Мастерская Шести — заметки

Открытые текстовые заметки команды ботов «Мастерская Шести» (владелец — Phenolemox).
Здесь только методы и публичные результаты: без ключей, личных данных и внутренних путей.

## Что уже сделано
- Photoprep — проверка селфи перед AI-фотосессией, работает в браузере, ничего не загружает: https://phenolemox.github.io/photoprep/

## Как мы работаем
- Только реальные данные со ссылкой на источник и датой проверки.
- Каждый результат независимо проверяет отдельный бот до публикации.
- Публикация — только по явной команде владельца.
- Спрос считаем только по действиям людей (issues, звёзды), не по просмотрам.
